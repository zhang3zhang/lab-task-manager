# Lab Task Manager
实验任务管理 API：一个用于练习独立后端开发的项目。
## 项目目标
开发一个用于记录实验任务及其进展的后端系统，
逐步完成需求分析、接口开发、数据库存储、测试和项目文档。
第一阶段只管理任务记录，不负责执行实验。

## 任务数据字段
| 字段 | 含义 | 规则 |
| --- | --- | --- |
| id | 任务唯一标识 | 系统生成，用户不能修改 |
| title | 任务标题 | 用户填写，不能为空 |
| status | 任务状态 | TODO（待开始）、DOING（进行中）、DONE（已完成） |
| createdAt | 创建时间 | 系统生成，用户不能修改 |

## 核心功能需求

### 1. 新建任务

- 输入：任务标题 title。
- 预期结果：创建一条任务，生成 id 和 createdAt，状态默认为 TODO。
- 返回：新建任务的完整信息。
- 异常情况：标题为空时，拒绝创建并提示原因。

### 2. 查询任务

- 查询全部任务：不需要输入，返回任务列表；没有任务时返回空列表。
- 查询单条任务：输入 id，返回对应任务的信息。
- 异常情况：查询的 id 不存在时，提示“任务不存在”。

### 3. 修改任务

- 输入：任务 id，以及需要修改的 title 或 status，至少提供一项。
- 预期结果：更新指定字段，未提供的字段保持原值。
- 返回：修改后的完整任务信息。
- 异常情况：任务不存在、标题为空或状态不合法时，拒绝修改并提示原因。

### 4. 删除任务

- 输入：任务 id。
- 预期结果：删除对应任务，并返回删除成功的反馈。
- 验证方式：删除后再次查询该 id，提示“任务不存在”。
- 异常情况：删除的任务不存在时，提示“任务不存在”。

## 计划技术栈

- Java：编写后端程序。
- Spring Boot：构建后端应用，提供 HTTP 接口。
- MySQL：持久化保存任务数据。
- Git / GitHub：记录修改历史并管理项目代码。
